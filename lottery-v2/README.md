# proveable Random Raffle Contracts

## about

This code is to create a proveable random raffle contract lottery.

## what we want it to do

1. Users can enter by paying for a ticket.
1. The ticket fees are going to go to the winter during the draw
1. After x period of time, the lottery will automatically draw a winner
   1. And this will be done programmatically
1. Using Chainlink VRF & Chainlink Automation
   1. Chainlink VRF -> Randomness
   2. Chainlink Automation -> Time based trigger
